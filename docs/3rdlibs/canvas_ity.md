# canvas_ity 的使用

感谢原作者提供这么好用的库:[github.com/a-e-k/canvas\_ity](https://github.com/a-e-k/canvas_ity)

`canvas_ity`可以让我在c++环境下下使用类似[html5 canvas api](https://html.spec.whatwg.org/multipage/canvas.html#the-canvas-element)
来进行绘图,这样我们可以基于此库来完成

1. 算法的可视化
2. 数据的可视化,帮助查找代码错误
